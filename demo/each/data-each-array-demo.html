data-each-array デモ

data-derive でグループ見出しを作り、行はグループごとに絞り込んだ 派生配列（rules.filter(...)）で描画しています。派生配列は結果の位置と 元の配列の位置の対応が式によって決まるため、行操作の書き戻し先を data-each-array で宣言します（data-each-key は必須）。

↑ / ↓ は、対象の行を表示上の前後の行が居る位置へ移します。 グループの中だけが入れ替わり、表示に出ていない要素の順序は変わりません。 下の元データが同時に変わることを確認してください。
