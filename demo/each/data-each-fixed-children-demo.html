data-each-before / data-each-after の再評価 デモ

data-each-before と data-each-after を付けた固定要素は 行ではないため、コンテナのスコープで評価されます。行の中の式が 行のデータで判定されるのに対し、固定要素の中の式は一覧そのもの （{{}} に items.length など）を参照できます。

「追加」「空にする」を押すと、見出しの件数と「該当なし」の表示が そのつど更新されます。一覧を隠すと data-each-done が外れ、出し直して描き終えた時点で戻ります。

  • くだもの（{{items.length}} 件）
  • {{item}}
  • 該当なし
