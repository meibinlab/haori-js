data-each-visible デモ（いま見えている行範囲）

data-each-visible をループコンテナに付けると、各行の交差状態から「見えている行範囲」を 指定した名前の変数として上位のバインドスコープへ公開します。スクロールすると下の表示が 追随します（画面個別の JavaScript は書きません）。

data-each-visible-root にスクロール枠のセレクタを指定します。省略するとビューポートが枠になります。
