haori:* イベント デモ

Haori は処理の節目でカスタムイベントを発火します。イベント名は haori: で始まり、 既定で親要素へ伝播（bubbles）するため document でまとめて受け取れます。 ここでは受け取ったイベントを下のログへ表示します。

画面個別の JavaScript を書かずに済ませたい処理は属性（data-{event}-*）で宣言できます。 イベントは、進捗表示や外部ライブラリとの連携のように属性では表せない用途のための出口です。

イベントログ

    1. バインドの変更（haori:bindchange）

    bindchange は、バインディングデータが書き換わったときに発火します。フォームの 双方向コミット（入力を変えて確定する）でも、data-{event}-bind による書き換えでも 通知されます。detail には変更前後の値と契機が入ります。

    メッセージ: {{message}} / カウント: {{count}}

    2. 行の増減と並べ替え（haori:eachupdate）

    eachupdate は差分の反映と行内容の描画が終わった時点で発火します。detail に 追加・削除・移動したキーが入るため、行ごとの個別イベントを待つ必要はありません。

    • {{item.name}}

    3. 表示の切り替え（haori:show / haori:hide）

    詳細の内容です。

    4. 通信（haori:fetchstart / haori:fetchend）

    名前: {{name}}

    5. 部分テンプレートの読み込み（haori:importstart / haori:importend）
