data-message デモ

data-message はメッセージの文字列を持つ属性で、data-message-level はその段階（error / warning / info / success）を表します。表示はページの CSS が担うため、 属性セレクタと attr() で好きな見せ方にできます。フェッチが失敗したときは ライブラリが自動で付けます。

スクリプトから付け外しする

画面個別の JavaScript からは addMessage() / addErrorMessage() / clearMessages() で 付け外しできます。iife 版のグローバルはモジュールの名前空間なので、クラスは Haori.Haori（ESM では import Haori from 'haori'）で取り出します。
