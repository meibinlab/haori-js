10. 個別デモ一覧

属性ごと・機能ごとの個別デモです。demo/ 配下のすべてのページをここから辿れます。

データバインディング

  • data-bind — JSON を要素に与え、テキストの補間で表示する最小例。
  • data-bind の入れ子 — 祖先からの継承と、内側の同名キーによる上書き。
  • data-bind の URL パラメータ形式 — key=value&key2=value2 形式の文字列でも与えられます。
  • data-derive — 親の選択から子の候補を導出し、配下の名前として供給します。
  • 組み込みヘルパー — haori.date / haori.now / haori.number / haori.pages と data-click-prevent。
  • セレクタ属性のテンプレート式 — セレクタを値に取る属性は評価結果をセレクタとして扱います。

条件分岐

  • data-if — 条件で表示・非表示を切り替えます。
  • data-if-false — 非表示の分岐に付く属性と、条件を戻したときの再表示。

繰り返し

  • data-each — 配列を行に展開する最小例。
  • data-each-index — 行番号を式から参照します。
  • data-each-key — 差分更新のキー（生成された行の data-row に入ります）。
  • data-each-before — 行の前に固定要素を残します。
  • data-each-after — 行の後に固定要素を残します。
  • data-each-before / after — 前後の固定要素を同時に使います。
  • data-row — 生成された行に自動で付く識別属性。
  • data-each-visible — スクロール中の可視行範囲を変数として公開します。
  • ページネーション — haori.pages() を使った一覧とページ送り。

フォーム

  • data-form — 入力値とバインディングデータの双方向同期。
  • data-form-arg — 収集した値を指定キーの下にまとめます。
  • data-form-object — 入力名の階層をオブジェクトとして収集します。
  • data-form-list — 同名の行入力を配列として収集します。
  • 編集可能な繰り返し行 — 0〜N 件の明細の追加・削除・並べ替えを配列へ反映します。
  • data-form-detach — 値の収集対象から外します。
  • data-if の送信除外 — 非表示の分岐にある入力は収集されません。
  • 同一 name ラジオの data-change-bind — 選択値を 1 キーへ書き、依存欄を出し分けます。
  • フィールド間検証 — data-validity と data-{event}-if で他の欄の値を条件にします。
  • 応答の値で遷移先を切り替える — バインドより後のアクションは使用直前に属性を再評価します。
  • 編集可能な行への copy / bind — 行を指したセレクタは対応する配列要素へ書き戻します。
  • 行の中で候補から 1 件を引く — 行ごとの取得結果から選択中の 1 件を hidden へ載せます。

クリックのアクション

  • data-click-fetch — クリックで取得し、応答をバインドします。
  • data-click-fetch-method / headers / content-type — メソッド・ヘッダー・本文形式の指定。
  • data-click-form — 対象フォームの値を送信します。
  • data-click-data — 送信データを属性で足します。
  • data-click-bind-arg / bind-params — 応答のバインド先とパラメータの指定。
  • data-click-before-run / after-run — 手続きの前後で画面個別の関数を呼びます。
  • data-click-confirm — 実行前に確認します。
  • data-click-click — 別の要素のクリックへつなぎます。
  • data-click-adjust — 数値の加算・減算。
  • data-click-open / close / dialog — ダイアログの開閉。
  • data-click-row-add / remove / prev / next — 行の追加・削除・並べ替え。
  • data-click-reset / refetch — 入力の初期値復元と再取得。
  • data-click-history — 履歴（pushState）の更新。
  • data-click-run — 任意の JS を宣言から呼び出し、既定動作も抑止できます。

通信

  • data-fetch — 表示時に取得して一覧へ展開します。
  • data-fetch（最小） — 1 キーだけを取得する最小例。
  • data-fetch-bind — 応答のバインド先を指定します。
  • data-fetch-bind-params — 取得時に渡すパラメータ。
  • data-fetch-arg — 応答を指定キーの下にまとめます。
  • data-fetch-form — 送信元のフォームを指定します。
  • data-fetch-headers — 追加のリクエストヘッダー。
  • data-fetch-method — メソッドと送信データの指定。
  • data-fetch-content-type — 本文の形式。
  • data-fetch-state — 読み込み中・成功・失敗を _fetch として参照します。
  • data-runtime="demo" — 確認モードで非 GET を GET へ正規化します。
  • <title> への実行時バインド — <head> も走査対象です。
  • data-intersect（無限スクロール） — 表示到達で次ページを追記します。
  • data-poll（定期取得） — 間隔・打ち切り・停止条件・一時停止。

状態保持・URL・画面連携

  • data-store（1画面目） — 指定キーをブラウザストレージへミラーします。
  • data-store（2画面目） — 復元と破棄。
  • data-url-param — URL のクエリをバインドします。
  • data-url-arg — クエリを指定キーの下にまとめます。
  • data-import — 部分テンプレートを読み込みます。
  • data-message — 表示用メッセージの定義と参照。

外部ライブラリ・イベント

  • data-enhance / data-enhance-new — 外部ライブラリの適用・再同期・破棄を宣言します。
  • data-external — 外部ライブラリの生成 DOM を自動監視から外します。
  • haori:* イベント — バインド変更・一覧更新・表示切替・通信・読み込みの節目で発火するイベントの観測。

実行時の設定（スクリプトタグの属性）

  • data-prefix — 解釈する属性の接頭辞を変えます。
  • data-dev — 開発モードの診断（未解決参照の警告）を強制します。
  • data-runtime="demo" — 静的サーバ向けに非 GET を GET へ正規化します。

不具合の再現ページ

  • confirm（ローカル更新） — 取得を伴わない確認ダイアログの再現。
  • confirm（bootstrap 版） — 公開版 + haori-bootstrap での再現。
  • data-click-click の順序 — 連鎖クリックの発火タイミングの再現。
  • data-click-click の順序（bootstrap 版） — 公開版 + haori-bootstrap での再現。
