式の正規表現リテラル デモ

テキスト補間（{{}}）や data-if・data-derive の式には、正規表現リテラル （/…/フラグ）を書けます。文字列リテラルと同じく 1 個のリテラルとして扱われ、中身は 解釈されません。全置換・判定・分割を、画面個別の JavaScript なしで宣言だけで書けます。

評価結果

宣言 結果
content.replace(/\[\/?(?:b|red|u)\]/g, '') {{content.replace(/\[\/?(?:b|red|u)\]/g, '')}}
/^\d+$/.test(code) {{/^\d+$/.test(code) ? '妥当' : '数字以外を含みます'}}
tags.split(/\s*,\s*/).join(' / ') {{tags.split(/\s*,\s*/).join(' / ')}}
content.replace(/\s+/g, '')（空白の除去） {{content.replace(/\s+/g, '')}}

data-if の条件にも書けます（コードが数字だけのときだけ表示）。

data-derive で分割した一覧

  • {{tag}}

注意

  • テキスト補間（{{}}）の中では }} を含む正規表現（/a{2}}/ など）は書けません。 プレースホルダの終端が先に見つかり、式が途中で切れます。
  • / が正規表現リテラルの開始になるのは値が来る位置だけです。 (100 + 8) / 2 のような除算はそのまま評価されます（結果: {{(100 + 8) / 2}}）。
  • 置換対象が固定の文字列だけなら replaceAll('[b]', '') でも書けます （replace に文字列を渡すと最初の 1 件しか置換されません）。
