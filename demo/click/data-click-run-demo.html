data-click-run デモ（イベント時に登録した関数を呼ぶ）

data-{event}-run は、フェッチを伴わない処理を宣言から呼び出すための属性です。 関数は Haori.handlers.register() で登録し、宣言には名前と引数だけを書きます。 -handler で呼んだ関数の this は起点要素、最初の引数は起点のイベントです。 同期的に false を返したときだけ既定動作を抑止します。
