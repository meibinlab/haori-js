編集可能な行への copy / bind

data-each と data-form-list を併用した行では、入力欄の値は 配列の要素データが権威です。行要素を data-{event}-copy / data-{event}-bind のセレクタで指すと、行フラグメントではなく対応する 配列要素へ書き戻されるため、複数の入力欄へまとめて値が流し込まれます。行ごとに 一意な id は data-each-index の値で組み立てます。
